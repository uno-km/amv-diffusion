Installation & Setup Guide

Complete guide for provisioning the native Bionic C++ engine, Python/Node.js SDKs, dual signed prebuilt artifacts, and hardware diagnostics.

⚡ Zero-Compilation 1-Click Provisioning (v1.3.0 Release)

Starting with v1.3.0, termux-diffusion automatically detects your Android CPU instruction set features (DotProd, FP16) and downloads cryptographically signed ARM64 prebuilt binaries verified with Ed25519 signatures. No on-device compilation tools (Clang/CMake/Ninja) are required!

1. 1-Click Package Manager Installation

1.1 Python Environment (PyPI)

# Step 1: Install python package from PyPI
pip install termux-diffusion

# Step 2: Auto-provision optimal ARM64 Bionic engine binary (takes ~5s)
termux-diffusion-install

# Step 3: Run pre-flight health diagnostic
termux-diffusion doctor

1.2 Node.js / TypeScript Environment (npm)

# Step 1: Install global CLI package from npm
npm install -g termux-diffusion

# Step 2: Auto-provision native prebuilt engine
npx termux-diffusion install

# Step 3: Run pre-flight diagnostic
npx termux-diffusion doctor

2. Dual Signed Prebuilt Artifacts & Auto-Selection Matrix

During installation, the engine probes /proc/cpuinfo and kernel getauxval(AT_HWCAP) to download the exact binary matching your processor:

Prebuilt Artifact Name Target ISA & CPU Features Verified Target Hardware Performance Characteristic
sd-cli-arm64-v8.2a-dotprod-fp16 ARMv8.2-A + DotProd + FP16 Vector Galaxy A35 (Exynos 1380), Galaxy S21 (Exynos 2100), Snapdragon 865+ 1.98x Faster Inference (SDXS ~4.08s)
sd-cli-arm64-v8a-cpu-baseline ARMv8-A Standard 64-bit NEON Broad Android ARM64 Devices, Android 8.0+ Universal Fallback Compatibility

3. 8-Tier Hardware & Platform Diagnostic Doctor

Run termux-diffusion doctor to execute the comprehensive 8-tier verification suite:

Tier Diagnostic Verification Item Validation Criteria & Target Standard
Tier 1 Android Bionic Platform Verifies Linux ARM64 kernel (aarch64) and Android OS environment.
Tier 2 RAM & Memory Headroom Checks physical RAM (≥4GB recommended) and zRAM/Swap configuration.
Tier 3 Storage & Gallery Permissions Verifies read/write access to ~/storage/pictures/TermuxDiffusion.
Tier 4 Native Engine Binary (sd-cli) Validates ELF64 header, execute permissions, and dynamic linker symbols.
Tier 5 Bionic Vulkan Driver Link Probes /system/lib64/libvulkan.so and GPU compute queue support.
Tier 6 CPU ISA Extensions Detects hardware DotProd (ASIMDDP) and FP16 (ASIMDHP) flags.
Tier 7 Shared C++ Runtime Checks libc++_shared.so and libomp.so library resolution.
Tier 8 Prebuilt Signature Check Verifies cryptographic Ed25519 signature on manifest-v1.3.0-dual.json.

4. Advanced Source Compilation Fallback (Optional)

For custom embedded architectures or upstream C++ development, you can force source compilation:

# Install native build toolchains
pkg install clang cmake make ninja git vulkan-loader vulkan-headers

# Force source compilation with device-detected compiler optimizations
termux-diffusion-install --source --jobs 4

5. Termux Background & Storage Optimization

  • Samsung Gallery Sync: Run termux-setup-storage once to allow automatic image indexing in Samsung Gallery / Google Photos.
  • Preventing Background Sleep: Execute termux-wake-lock before running multi-minute inference tasks to block Android Doze CPU throttling.
