Complete API Reference

Comprehensive specification for Python SDK, Node.js TypeScript API, and unified CLI binary interface in termux-diffusion v1.3.0.

1. Python SDK (`termux_diffusion`)

1.1 termux_diffusion.generate(...)

Synchronous function that triggers on-device Stable Diffusion inference, automatic Bionic prebuilt detection, and Samsung Gallery synchronization.

from termux_diffusion import generate, GenerationResult

result: GenerationResult = generate(
    prompt: str,
    model: str = "sdxs",
    steps: Optional[int] = None,
    cfg_scale: Optional[float] = None,
    width: int = 512,
    height: int = 512,
    output_path: Optional[str] = None,
    negative_prompt: Optional[str] = None,
    sampler: Optional[str] = None,
    schedule: Optional[str] = None,
    vae_tiling: bool = False,
    seed: int = -1,
    threads: Optional[int] = None,
    init_img: Optional[str] = None,
    strength: Optional[float] = None,
    lora_dir: Optional[str] = None,
    clip_skip: Optional[int] = None,
    control_net: Optional[str] = None,
    control_image: Optional[str] = None,
    control_strength: Optional[float] = None,
    taesd: Optional[str] = None,
    device: str = "cpu"
) -> GenerationResult
Parameter Type Default Description & Best Practices
prompt str Required Positive description of the target visual synthesis.
model str "sdxs" Preset identifier: "sdxs", "anime", "realistic", "speed", or local GGUF path.
steps int Auto Denoising steps. Defaults: SDXS=2, Anime=4~6, Realistic=6~8.
cfg_scale float Auto Classifier-Free Guidance. Defaults: SDXS=1.0, Anime=1.5, Realistic=4.0.
vae_tiling bool False Essential for 1.5GB+ models. Slashes peak RAM by 70% to prevent Android OOM crashes.
sampler str "euler_a" Sampling method: "euler_a", "euler", "heun", "dpm2", "dpm++2s_a", "dpm++2m", "lcm".
schedule str "default" Noise schedule: "default", "discrete", "karras", "exponential", "ays", "gits".
threads int None CPU thread count. Defaults to optimal cluster size (4 big cores on Exynos 1380 / 2100).
seed int -1 RNG seed for deterministic replication (-1 for random).

1.2 GenerationResult Object Structure

@dataclass
class GenerationResult:
    path: str             # Absolute file path of generated image in working directory
    gallery_path: str     # Path in Samsung Gallery (~/storage/pictures/TermuxDiffusion/...)
    elapsed_sec: float    # Exact end-to-end inference latency in seconds
    seed: int             # Evaluated integer seed used for generation
    model_name: str       # Resolved GGUF model identifier
    metrics: Dict[str, Any] # Dictionary of sub-phase latencies (Load, Cond, Sample, VAE)

1.3 TermuxWakeLock Context Manager

Prevents Android OS Doze mode from freezing CPU execution during long inference tasks (>3 minutes).

from termux_diffusion.platform import TermuxWakeLock

# Automatic acquisition and release via context manager
with TermuxWakeLock():
    res = generate(prompt="Cyberpunk landscape", model="realistic", steps=8, vae_tiling=True)
    print(f"Generated safely: {res.path}")

2. Node.js / TypeScript SDK

const { generate } = require("termux-diffusion");

async function main() {
    const result = await generate({
        prompt: "(masterpiece:1.2), beautiful Korean woman in cafe, soft morning light, 85mm f1.4",
        model: "sdxs",
        steps: 2,
        cfgScale: 1.0,
        width: 512,
        height: 512
    });
    console.log(`Generated in ${result.elapsedSec}s: ${result.path}`);
    console.log(`Gallery Path: ${result.galleryPath}`);
}
main();

3. Unified CLI Reference (termux-diffusion)

Command / Flag Shorthand Description & Example
termux-diffusion generate gen Primary synthesis command. Accepts positional prompt string.
--model <name> -m Model preset (sdxs, anime, realistic, speed) or local GGUF path.
--steps <int> -s Denoising step count (e.g. -s 2 for SDXS, -s 6 for Realistic).
--cfg-scale <float> -c Guidance scale (e.g. -c 1.0 for SDXS, -c 4.0 for Realistic).
--vae-tiling - Tiled VAE decoding for 70% lower memory footprint.
--width / --height -W / -H Output spatial dimensions (default: -W 512 -H 512).
--sampling-method <name> --sampler Sampler: euler_a, lcm, dpm++2m, heun, dpm2.
--schedule <name> - Noise schedule: default, karras, ays, exponential.
termux-diffusion doctor - 8-Tier hardware and prebuilt diagnostic test suite.
termux-diffusion install - Bootstrap and provision native ARM64 Bionic engine binaries.
