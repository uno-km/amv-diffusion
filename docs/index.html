Termux-Diffusion

Native On-Device Stable Diffusion Runtime for Android Termux & ARM64

1-Line Quick Installation

Install the official package directly into your runtime:

pip install termux-diffusion
# or: npm install termux-diffusion

The Engineering Challenge

Generating AI images on mobile devices typically requires cloud API dependencies or heavy virtualized container layers (PRoot) that quickly exceed RAM limits.

The Architectural Breakthrough

Executes quantized Stable Diffusion models directly on Android Bionic libc with NEON SIMD vector acceleration and direct Samsung Gallery indexing.

Key Capabilities & Built-in Hardening

Zero-PRoot Native ARM64 Bionic

Executes directly without root permissions, virtual machines, or PRoot Linux overhead.

Dual Python & Node.js Engine

Provides comprehensive CLI and programmatic APIs across both Python and JavaScript.

Samsung Gallery Auto-Indexing

Automatically broadcasts Android MEDIA_SCANNER intents to register generated art in Gallery.

Supported Compute Kernels & Operations

Subsystem Category Operations & Kernels Status
Diffusion Engine SD 1.5, SD Turbo, LCM, Tiny-SD, GGML Quantized Weights Production
Vector Acceleration ARM64 NEON SIMD, FP16 Compute, Multi-Threaded Tiling Production
Media Integration PNG/WebP Export, Android MediaStore Intent Broadcast Production

Canonical Usage Example

import termux_diffusion as td

# 1. Generate image on Android hardware
image_path = td.generate(
    prompt="Cyberpunk Seoul city at night, neon lights, 8k",
    model="sd-turbo",
    steps=4
)
print(f"Generated and saved to Gallery: {image_path}")

import { generate } from "termux-diffusion";

const result = await generate({
  prompt: "Cyberpunk Seoul city at night, neon lights, 8k",
  model: "sd-turbo",
  steps: 4
});
console.log("Image created:", result.outputPath);
