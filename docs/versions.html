2. Comprehensive Release Notes

v1.3.0 (2026-08-25) — Dual-Prebuilt & Hardware Auto-Selection Release

  • Hardware SIMD Vector Auto-Selection: Introduces sd-cli-arm64-v8.2a-dotprod-fp16 yielding 1.98x faster inference on Exynos 1380 (Galaxy A35) and Exynos 2100 (Galaxy S21) over baseline ARMv8-A.
  • Zero-Compilation Instant Provisioning: 100% prebuilt artifact delivery eliminating on-device Clang/CMake/Ninja build bottlenecks.
  • Python 3.14 Compatibility: Escaped argparse help string formatting (~70%% lower peak memory) resolving TypeError: %o format exceptions on Termux Python 3.14.
  • Bionic WebP Healer: Neutralized if(ANDROID) NDK cpu-features dependency in libwebp CMakeLists.
  • Adreno / Mali Vulkan Protection: Disabled unsupported desktop NV extensions to prevent shaderc 5447 errors during shader generation.
  • Cryptographic Manifest Verification: Release artifacts secured via Ed25519 detached signatures (RFC 8032).

v1.1.2 (2026-08-23) — TypeScript & npm Packaging Stabilization

  • Added full TypeScript interface definitions (index.d.ts) for Node.js developers.
  • Optimized npm tarball structure reducing unpacked size to 85.6 KB.

v1.1.1 (2026-08-20) — Gallery MediaSync & Process Reaper

  • Samsung Gallery Integration: Automatic dispatch of android.intent.action.MEDIA_SCANNER_SCAN_FILE broadcasts to index generated PNG/WebP files in Samsung Gallery and Google Photos.
  • Process Reaper: Attached process group cleanup ensuring zero orphan/zombie sd-cli instances on SIGINT / Ctrl+C.
  • Advanced CLI Parameters: Added --clip-skip, --lora-dir, --control-net, and --taesd flags.

v1.1.0 (2026-08-18) — Node.js Dual Engine & 8-Tier Doctor

  • Published official npm package termux-diffusion providing native CLI and programmatic JS binding.
  • Implemented 8-Tier hardware diagnostic suite (termux-diffusion doctor) checking Bionic linker, Vulkan driver, memory limits, and ISA extensions.

v1.0.0 (2026-08-15) — Foundation Release

  • Initial open-source release on PyPI.
  • Native C++ ARM64 Bionic engine execution without PRoot or virtual containers.
  • Support for GGUF quantized models (Q8_0, Q4_0, Q4_K).
