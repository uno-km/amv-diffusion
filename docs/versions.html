Version Archive & Chronological Changelog

Complete history of official releases, prebuilt binary assets, and kernel patches

v1.3.1 - Structured Error Diagnostics & Dual Registry Production Release Latest

Release Date: 2026-08-27 | Tag: v1.3.1

  • Structured Error Diagnostics: Formatted fail-fast diagnostic error messages with parameter name, resolved absolute path, and targeted recovery remedies.
  • CLI Exception Handling: Integrated comprehensive try-catch wrappers returning deterministic process exit codes (ExitCode.CLI_ERROR, ExitCode.BUILD_ERROR).
  • Dual Registry Synchronization: Fully aligned npm and PyPI distribution metadata, including automated PyPI release pipelines.
  • Multi-SoC Vulkan Acceleration: Native Vulkan acceleration on Snapdragon Adreno 830 (Galaxy S25) and Exynos Mali-G68/G78 with safe memory fences.
  • Production Presets: Pre-calibrated --preset fast, --preset balanced, and --preset anime_experimental.

v1.3.0 - Dual-Prebuilt Fast-Track Architecture

Release Date: 2026-08-25 | Tag: v1.3.0

  • Integrated Dual-Prebuilt architecture (ARMv8.2-A CPU Optimized + ARMv8-A Baseline).
  • Achieved 4.08s (1.98x speedup) on Galaxy A35 using ARM DotProd/FP16 SIMD vectorization.
  • Introduced --vae-tiling memory defense reducing peak decode allocation by ~70%.

v1.2.0 - TOP 7 Advanced Inference Parameters

Release Date: 2026-08-24 | Tag: v1.2.0

  • Added support for Img2Img, ControlNet, LoRA adapter directories, CLIP skip, TAESD, and custom samplers.
  • Engineered 8-tier interactive Doctor diagnostics and CPU cluster affinity management.
