Quickstart & Execution Recipes

Get started with on-device image generation in 10 seconds. Includes copy-paste recipes for SDXS, Anime LCM, and Realistic Vision.

1. 10-Second Quickstart (초고속 첫 이미지 생성)

Generate your first photorealistic image in 4 seconds directly from the terminal:

# 1. Generate ultra-fast SDXS image (Auto-downloads weights on 1st run)
termux-diffusion generate "a small red robot on a wooden workbench, photorealistic" -m sdxs

2. Python SDK Quickstart

import termux_diffusion as td

# Generate 512x512 image on Galaxy A35 / S21
result = td.generate(
    prompt="(masterpiece:1.2), beautiful Korean woman in cafe, cozy knit sweater, soft morning window light, 85mm f1.4",
    model="sdxs",
    steps=2,
    cfg_scale=1.0,
    width=512,
    height=512
)

print(f"Generated in {result.elapsed_sec:.2f}s!")
print(f"Saved to: {result.path}")
print(f"Samsung Gallery Path: {result.gallery_path}")

3. Node.js / JavaScript Quickstart

const { generate } = require("termux-diffusion");

async function run() {
    const result = await generate({
        prompt: "anime warrior girl, cyber armor, glowing katana, masterpiece, 8k",
        model: "anime",
        steps: 4,
        cfgScale: 1.5,
        vaeTiling: true
    });
    console.log(`Rendered in ${result.elapsedSec}s: ${result.path}`);
}
run();

4. Curated Model Golden Recipes (모델별 황금 레시피)

Recipe 1: SDXS (Real-Time 4-Second Generation)

termux-diffusion generate   "a small red robot on a wooden workbench, photorealistic, 8k"   -m sdxs -W 256 -H 256 -s 1 --cfg-scale 1.0
  • Latency: 4.08s (Galaxy A35) / 3.83s (Galaxy S21)
  • Best For: Real-time mobile apps, chatbots, instant visual mockups.

Recipe 2: DreamShaper 8 LCM (Vibrant 2D/2.5D Anime)

termux-diffusion generate   "anime girl warrior in cyber armor, glowing katana, highly detailed background, masterpiece, 8k"   -n "low quality, blurry, bad anatomy, deformed, extra limbs"   -m anime -W 512 -H 512 -s 4 --cfg-scale 1.5 --sampling-method lcm --vae-tiling
  • Latency: 7.0 ~ 9.4 minutes on CPU
  • Rule: Always append --vae-tiling to prevent memory allocation spikes.

Recipe 3: Realistic Vision V6.0 B1 (Golden Photorealism)

termux-diffusion generate   "(masterpiece, best quality:1.2), professional portrait photo of a beautiful 24yo Korean woman, cozy knit sweater, cafe background, soft morning window light, 85mm f1.4 lens, natural skin texture, lifelike, sharp focus"   -n "(worst quality, low quality:1.4), (deformed iris, deformed pupils:1.3), cgi, 3d, render, cartoon, plastic skin, doll, ugly"   -m realistic -W 512 -H 512 -s 6 --cfg-scale 4.0 --sampling-method euler_a --vae-tiling --seed 777
  • Golden Rule: Keep CFG at 4.0 to avoid high-contrast color burn. Use lens keywords (85mm f1.4 lens, soft window light) instead of literal 'skin pores'.

5. Img2Img Synthesis Recipe

# Transform existing photo into anime watercolor art
termux-diffusion generate   "watercolor anime portrait, soft brush strokes, masterpiece"   -i input_photo.png --strength 0.65 -m anime --vae-tiling
