High-Precision Parameters & Tuning

Deep-dive into VAE Tiling, CLIP Layer Skipping, LoRA weight merging, TAESD autoencoders, and multi-threaded CPU tuning on Android.

1. VAE Tiling (--vae-tiling / vae_tiling=True)

The essential safeguard for running 1.5GB+ models on Android mobile hardware.

  • Mechanism: Full monolithic VAE decoding requires allocating a [1, 4, 64, 64] → [1, 3, 512, 512] tensor graph that spikes intermediate RAM to 1.2 GB ~ 1.5 GB. --vae-tiling splits spatial dimensions into overlapping 256×256 tiles with Gaussian feathering.
  • Benefit: Slashes peak memory by ~70% (from 1,240MB down to <200MB), preventing Android LowMemoryKiller (LMK) aborts on 6GB RAM devices like Galaxy A35.
  • Recommendation: Always enable for anime and realistic presets. Not required for sdxs (uses lightweight TAESD).

2. CLIP Layer Skipping (--clip-skip 1|2)

  • Concept: CLIP text encoder processes token embeddings across 12 transformer layers. Skipping the final layer (clip_skip=2) extracts more conceptual, less literal semantic features.
  • Best Use Case: Essential for Anime and 2D illustration models (DreamShaper 8 LCM) to produce richer artistic composition without over-constraining anatomy.

3. Dynamic LoRA Weight Merging (--lora-dir <path>)

# Place .safetensors LoRA files in ~/loras/
termux-diffusion generate "portrait " -m realistic --lora-dir ~/loras/

On-the-fly matrix rank decomposition merges low-rank adapter weights directly into the UNet tensor graph without pre-baking, preserving model storage.

4. Tiny AutoEncoder for Stable Diffusion (--taesd <path>)

  • Latency Reduction: Replaces standard 16-layer VAE with a tiny 4-layer convnet, cutting latent decoding time from 7.3s down to 0.20s on Exynos 1380.
  • Built directly into the sdxs model preset. Can be supplied to anime or realistic for near-instant preview generations.

5. Sampler & Noise Scheduler Compatibility Matrix

Sampler (--sampler) Schedule (--schedule) Recommended Steps Optimal Model Architecture Behavior & Stability
euler_a default 1 ~ 2 (SDXS) / 6 (Real) SDXS, Realistic Vision Fastest first-order ancestral solver. Uncorrupted distillation.
lcm karras / default 4 ~ 6 DreamShaper 8 LCM Consistency trajectory solver. High saturation, cel-shading.
dpm++2m karras 8 ~ 12 Realistic Vision (HQ) Second-order multi-step. Highest photorealistic fidelity.
heun / dpm2 exponential 15 ~ 20 Standard SD 1.5 Base Double-evaluation per step. Do NOT use on SDXS.

6. Multi-Threaded CPU Affinity Tuning (-t <int>)

Exynos 1380 (Galaxy A35) and Exynos 2100 (Galaxy S21) feature big.LITTLE heterogeneous CPU architectures:

  • Optimal Thread Count: 4 threads (pins execution exclusively to Cortex-A78 / Cortex-X1 big cores).
  • Over-threading Warning: Setting threads to 8 forces work onto Cortex-A55 efficiency cores, creating thread synchronization stalls that slow down inference by ~18%.
