Benchmarks & Hardware Telemetry

Rigorous hardware profiling, empirical latency comparisons, and memory telemetry measured on physical Samsung Galaxy A35 and Galaxy S21 devices.

📊 Baseline vs. Optimized Prebuilt Acceleration (1.98x Speedup)

On the Exynos 1380 (Galaxy A35), the ARMv8.2-A + DotProd + FP16 Optimized Prebuilt delivers a 1.98x end-to-end speedup over standard ARMv8-A baseline binaries, slashing UNet sampling time by 53.2% and VAE decoding by 56.9%.

3. Memory Telemetry & VAE Tiling Analysis

Full-precision VAE decoding of a 512×512 latent grid creates intermediate tensor spikes up to 1.2 GB, which triggers Android LowMemoryKiller (LMK) on 6 GB RAM devices. --vae-tiling subdivides decoding into overlapping 256×256 spatial tiles.

VAE Mode Peak Memory Allocation RAM Reduction Android OOM Risk Tile Overlap Blend
Standard Full VAE Decode 1,240 MB ~ 1,480 MB 0% (Baseline) HIGH (Crash on 6GB RAM) N/A (Monolithic)
--vae-tiling (Active) 185 MB ~ 240 MB ~70% ~ 82% Reduction ZERO (100% Stable) Gaussian Feathering (0 Seams)
